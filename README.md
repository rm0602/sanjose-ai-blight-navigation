# Pathpal: AI for Safe routes home, blight reporting.

Client: City of San José, Blight and Navigation
Team: Ryan M. Man N. Rishaan S. Deserae L. Tyler P., Aug–Oct 2026
My part: I designed the UI, data architecture and built the real-time routing engine.

## The problem
Beta testers currently have the application, but the 511 traffic feed API integration breaks today due to an unannounced endpoint migration.

## What we built
• Navigates and logs: The prototype automatically ingests 511 traffic feeds and Google Maps data to calculate low-blight walking paths for kids while tracking their location history.
• Displays maps and alerts: The user sees a simplified map with highlighted safe pathways, real-time safety alert badges, and a direct button to photograph and upload neighborhood blight reports.
• Chooses final pathways: A human still decides which specific street hazards constitute a critical safety risk and whether a reported piece of blight requires official city intervention.

## What I would do next

so I want to build a crowdsourced sidewalk-illumination tracker and
